# M2 구현·재적용 작업 기록

2026-09-29 사용자 지시: “그러면 m2까지 구현한뒤 다시적용”.
M2 3·4단계 구현까지 범위를 확장한다. M1 미완료 측정, 사람의 종료 점검,
D3–D8 등 제안 결정은 자동 승인하거나 완료로 바꾸지 않는다.

## 구현과 통합 순서

- [x] 현재 관찰 기반 업무 근거 검토를 그래프 책임으로 분리한다.
- [x] 식별자·필드 근거 부족과 실제 중복·불일치를 구분하고 한도 내 복구한다.
- [x] 의미 기반 캐시 저장·조회·갱신·실패 재시도/무효화와 cache.enabled를 구현한다.
- [x] 중계의 관찰 전용 시연 기록과 값 변화의 의미 입력 변환을 구현한다.
- [x] 검증한 캐시 행동과 모델 행동이 동일한 현재 상태·실행·사후 검사를 거치게 한다.
- [x] 공공 코드 자료의 다운로드·출처 기록, 합성 HBL/송장/포장명세서 PDF를 구현한다.
- [x] 미취합·중량 차이·개수 차이·품명 차이·컨테이너 오류와 팩스풍 열화를 구현한다.
- [x] PaddleOCR·측정 비전 모델 추출, 위치 근거, 교차 검증 기반 확신도를 구현한다.
- [x] 차단 오류가 있는 추출 결과는 입력하지 않고, 준비된 추출 레코드를 Brain에 연결한다.
- [x] fake/replay 회귀 검사와 양 저장소 필수 검사를 수행한다.
- [x] 동일 조건의 캐시 전후 및 서류 오류 측정과 실제 화면 재적용을 수행한다.

## 고정 경계

두뇌의 환경 접근은 relay뿐이다. 캐시는 관찰 ref·좌표·AutomationId·입력값·자격증명을
영속 저장하지 않으며 현재 관찰의 의미 대상에 다시 대응한다. 새 경로의 검증 전 승격,
과거 관찰을 합쳐 현재 행 검증으로 간주하는 처리, 실제 기업/평가 시드 사용은 하지 않는다.
테스트는 fake/replay, 실제 모델은 ModelClient 비용 한도를 거친다. 데이터 생성 정답은
채점 전용이며 추출기와 모델 입력에 섞지 않는다. 영속 경험 학습과 실행 중 상태는 구분한다.

## 측정 상태

기능 구현·회귀 검사·개발 파일럿과 재적용을 완료했다. GitHub 동기화 전 재검사에서 비공개 423개, 공개 408개 일반 테스트 통과.
공개 [실측 보고서](../../agent-sawon-bench/evidence/m2/README.md)에 실패·미실행을 포함했다.

- 경량 기본+상위 1회 복구로 화면 완료 4건, 모두 저장·최종 조회 10/10, 중복·무권한 전송 0.
- 비교 표본: 캐시 없음 28호출/$0.0531266/64.19초 → 캐시 19호출/$0.03675117/52.72초.
- 한글 서류→OCR·비전→검사→ERP→결재 대기 통과: 총20호출/$0.03891301.
- 오류 6조건 모두 탐지, 정정 판정 7/8. 정상 팩스는 2개 OCR 오독을 교차 검증이 발견해 차단했다.
- M1 전체 매트릭스, M2 여러 변형·3회 반복, 실제 캐시 실패 복구율, 사람 시연 기록의 실제 수기 검증,
  팩스 정확도 개선과 D6–D8 결정은 남아 있다. 기능 구현 완료가 마일스톤 종료 승인이라는 뜻은 아니다.

현재 [코드 흐름](code-flow.md)을 갱신했다. M2 실행 설정은 `config/brain.m2.toml`,
캐시 없는 동일 복구 정책은 `config/brain.m2-no-cache.toml`이다. 문서 처리 설정과 한글 OCR은
`config/pipeline.toml`, `config/pipeline.korean.toml`이며 `pipeline.workflow`가 하네스와 연결한다.
