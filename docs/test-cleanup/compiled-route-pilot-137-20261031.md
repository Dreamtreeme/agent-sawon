## 비교와 한계

136 인출은 62.449초·원격 7회였고 이번은 21.310초·0회다. 두 실행의 새 탐색 기록과
편찬 경로도 달라졌으므로 시간 차이 전체를 특정 코드 변경의 단독 효과로 확정하지 않는다.
이번에 직접 확인한 것은 편찬 12개 그룹의 순서 실행, 정상 구간의 모델 호출 제거,
