# 테스트 유지 기준

테스트 수 자체를 품질 지표로 사용하지 않습니다. 기본 회귀 모음에는 다음 중 하나를 독립적으로
입증하는 테스트를 둡니다.

1. 공개 입출력 계약이나 저장 형식의 구체적인 결함을 잡습니다.
2. 현재 실행 경로의 상태 전이, 실행 경계 또는 성공 판정을 검증합니다.
3. 실제 파일럿에서 발생한 오류를 원인 하나로 재현하며 수정 전에는 실패합니다.
4. 화면 캐시와 웜 메서드가 새 값·현재 화면에 올바르게 재결합하거나 안전하게 폴백합니다.
5. 비밀, 비용, 허용 창과 기록 무결성 같은 운영 경계를 검증합니다.

도우미 자체만 검사하거나, 프롬프트 문자열 존재만 단언하거나, Pydantic·pytest 동작을 다시
검사하거나, 현재 생산 경로가 호출하지 않는 구형 경로를 유지하는 테스트는 삭제·통합 후보입니다.
무거운 통합 테스트는 하위 테스트가 잡지 못하는 반환값·예외·상태 조합을 명시해야 합니다.

테스트 개수와 한 번의 실행 시간은 고정 회귀 계약이 아닙니다. 정리 전후에는 실패 탐지 대상,
statement/branch coverage, assertion과 실행 시간을 함께 비교합니다. 전체 기준선은 현재
`python -m pytest` 결과로 측정하며 날짜별 과거 보고서의 개수를 복사하지 않습니다.
