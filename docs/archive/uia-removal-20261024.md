# UIA 제거 기록 · 2026-10-24

처음에는 UIA를 시도했지만, 요소 트리가 부정확하게 전달되고 노출되는 정보가
빈약했기 때문에 삭제했다.

bench의 요소 트리 수집·직접 컨트롤 조작, 선택자 기준선·기록기, 오류 주입기,
전용 프로브·테스트와 설치 의존성을 제거했다. core의 트리 참조 전달 경로와
관찰 모드 선택, 관련 주석을 제거하고 캡처와 OCR 내부 장면을 분리했다.

Win32 창/프로세스·DPI·포커스·캡처·물리 입력은 현행 화면 실행에 필요하므로 유지한다.
TokenUIAccess는 Windows 토큰 권한 조회이며 요소 트리를 읽는 기능이 아니다.
Mock ERP 자체의 기본 접근성 라벨과 시드 ID 조건은 앱/평가 데이터이며,
에이전트나 relay는 이를 관찰하거나 선택자로 사용하지 않는다.

과거 evidence와 실행 기록은 수정하거나 재판정하지 않았다. 기존 문서 중 이전
경로를 설명하는 자료는 아카이브로 이동했다. 제품 파일에는 삭제 이유를 남기지 않았다.

공개 Python 계약 패키지를 0.5.0으로 올리고 양쪽 소비 범위를 함께 갱신했다.
RefTarget, PointTarget, SelectOptionAction과 직접 옵션 선택 모델 응답을 제거했다.
옵션을 고르는 업무 의도는 클릭·키보드로 구현하므로 유지한다.

Mock ERP의 ValuePattern 전용 새 행 승격 보정도 제거했다. 물리 입력의
DataGridView.EndEdit 호출은 유지한다.

## 검증

- core: 703 passed (48.21초), bench: 536 passed, GUI 1건 제외 (14.58초).
- Ruff lint/format, 공개 스키마 export 검사와 diff 공백 검사 통과.
- Mock ERP 도메인 34건 통과, 앱 Release 빌드 성공.
- 091 저장 기록 전체 그래프 오프라인 재생: success, 모델 응답 20회,
  행동 31건, 노드 94회가 일치했고 남은 재생 입력은 없다.
- 삭제한 테스트는 삭제한 트리 수집·패턴 조작·기준선/기록기·오류 주입기
  대상이다. 인증·창/캡처 범위·물리 좌표·DPI 복원·외부 작업자 비용 검증은 남긴다.
- 실제 ERP 화면 실행과 유료 호출은 하지 않았다. 원격 CI는 이번 변경으로
  재실행하지 않았다. 공개 계약 0.5.0은 양 저장소를 함께 설치해야 한다.
