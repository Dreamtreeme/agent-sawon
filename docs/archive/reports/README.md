# 역사 보고서

이 디렉터리의 문서는 작성 당시의 코드, 모델, 설정, seed와 측정 결과를 보존합니다.
**현재 실행 지침이나 복원 요구사항이 아닙니다.** 현재 구현을 변경할 때는 먼저
[`docs/current-runtime.md`](../../current-runtime.md),
[`docs/contracts.md`](../../contracts.md),
[`docs/code-flow.md`](../../code-flow.md)를 확인합니다.

보고서 내용과 수치는 소급 수정하지 않습니다. 오래된 링크와 파일명도 당시 기록의 일부일 수
있습니다. 현재 문서에서 이 결과를 인용할 때는 날짜와 당시 실행 조건을 함께 적습니다.
